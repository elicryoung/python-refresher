# Python Refresher

> A practical reference for learning, relearning and refreshing Python.

Concise explanations, syntax tables, worked examples and hands-on exercises.

Designed for desktop learning and quick mobile revision.

## How to Use This Repository

1. Choose a topic from the index below.
2. Read the reference notes.
3. Complete the corresponding Python exercises.
4. Revisit the topic whenever you need a refresher.
