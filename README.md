# Python Refresher

A structured, beginner-friendly Python curriculum that
progresses from fundamental syntax to independent
practical problem-solving.

## Learning Principles

- Follow the modules in numerical order.
- Each lesson builds on previously introduced concepts.
- No exercise requires concepts from future lessons.
- Learn the concept before attempting its exercises.
- Attempt exercises independently before viewing solutions.
- Progress only when you can apply the concept independently.

## Lesson Structure

Each lesson contains:

1. Prerequisites
2. Concept explanation
3. Syntax
4. Worked examples
5. Expected outputs
6. Important rules
7. Progressive exercises
8. Common mistakes

## Exercise Difficulty

Each concept includes one to five exercises of
increasing difficulty.

| Level | Description |
| --- | --- |
| 1 | Basic syntax |
| 2 | Understanding and application |
| 3 | Independent implementation |
| 4 | Combined concepts |
| 5 | Practical problem-solving |

## How to Practise

Each module contains:

- notes.md — explanations and reference material.
- exercises.py — practical coding exercises.

Read the relevant lesson before attempting its exercises.

Write your own solution in the solution section.
Run your code and compare it with the expected output.

Keep completed exercises inactive using triple quotes
before moving to the next exercise.
